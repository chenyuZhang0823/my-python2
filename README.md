# 矩阵计算器使用说明书
## 一、程序简介

本程序是一个基于命令行的矩阵计算工具，支持对两个矩阵进行加法和乘法运算。用户通过键盘输入矩阵的行数、列数和具体元素，程序会自动计算结果并显示。
## 二、运行环境

需要 Python 3.x 环境。依赖 src.matrix 模块，需保证该模块中的 Matrix 类已正确实现。
## 三、启动方式

在终端或命令行中，进入程序所在目录后执行：

python 文件名.py

启动后，程序会显示：

=== 矩阵加法与乘法 ===

随后依次提示输入矩阵 A 和矩阵 B。
四、输入流程
1. 输入行数和列数

程序会依次询问：

请输入矩阵 A 的行数:
请输入矩阵 A 的列数:

输入要求：必须是正整数，即大于 0。若输入非整数或小于等于 0，程序会提示错误并要求重新输入。
2. 逐行输入矩阵元素

确定行列数后，程序提示：

请逐行输入矩阵 A 的元素（每行 N 个数，用空格分隔）：
第 1 行:
第 2 行:
……

输入要求：每行必须输入恰好 N 个数，N 为列数。数字之间用空格分隔。支持整数（如 3）和小数（如 3.14、1e-5）。若某行数字个数不对或含非数字内容，程序会提示重新输入该行。
3. 重复输入矩阵 B

矩阵 A 输入完成后，按相同流程输入矩阵 B。
五、输出结果

输入完成后，程序自动输出：

A + B:
矩阵加法结果

A × B:
矩阵乘法结果

运算规则提示：加法要求 A 与 B 的行数、列数完全相同。乘法要求 A 的列数等于 B 的行数。

若条件不满足，程序会捕获异常并提示：

无法相加: 错误原因
无法相乘: 错误原因
